# 网页版俄罗斯方块

纯静态实现，无框架、无构建、无外部 CDN。双击 `index.html` 即可开玩，也可以用任意静态服务器托管。

```bash
# 任选一种
open index.html
python3 -m http.server 8000   # 然后访问 http://localhost:8000
```

## 玩法

- 7 种方块，7-bag 随机保证每 7 个内不重复
- SRS 旋转与踢墙，软降、硬降、500ms 锁定延迟（移动/旋转最多重置 15 次）
- 暂存（每块一次）、Next 预览 5 个、幽灵落点
- 计分：单行 100、双行 300、三行 500、四行 800，再乘当前等级；软降每格 +1，硬降每格 +2
- 每 10 行升一级，下落间隔随等级缩短
- 游戏结束判定：新方块生成位置被占用

## 操作

| 按键 | 作用 |
| --- | --- |
| ← / → | 左右移动 |
| ↑ 或 X | 顺时针旋转 |
| Z 或 Ctrl | 逆时针旋转 |
| ↓ | 软降 |
| 空格 | 硬降 |
| C 或 Shift | 暂存 |
| P | 暂停 / 继续 |
| R | 重新开始 |

触屏设备会自动显示方向键、旋转、暂存、硬降与暂停按钮，长按可连续移动。

## 测试

核心逻辑是纯函数，可直接在 Node 中运行：

```bash
node --test tetris/test/logic.test.mjs
```

覆盖消行与计分、等级加速、7-bag、SRS 踢墙、旋转几何、硬降、游戏结束、暂存限制与边界碰撞。

## 文件

- `index.html` — 页面结构
- `style.css` — 深色主题与响应式布局
- `game.js` — 规则逻辑（UMD 导出）+ 渲染 + 输入
- `test/logic.test.mjs` — 无头逻辑测试
